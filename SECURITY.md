# Security Policy

## Supported versions

Security fixes are applied to the latest development state on the default branch.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities.

Use private disclosure by contacting the maintainers directly (out-of-band channel). Include:

1. Affected version/commit.
2. Reproduction steps or proof-of-concept.
3. Impact assessment.
4. Suggested remediation (if available).

## Response expectations

- Initial acknowledgement: target within 7 days.
- Triage and severity classification: as soon as reproducible.
- Fix publication: coordinated after remediation is available.
